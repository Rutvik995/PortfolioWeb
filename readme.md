# Rutvik | 3D Interactive Portfolio

An immersive, interactive 3D WebGL developer room built with Three.js.

## Features
- **Photorealistic Stylized 3D Room**: Real-time baking, lighting, and ambient shadows.
- **Interactive TV Music Player**: Full-screen Smart TV music soundsystem playing full-length soundtracks with live audio-reactive equalizer visualizers and ambient neon backlighting.
- **Responsive Controls**: Direct 3D raycast interaction, intuitive camera orbit/pan/zoom, and floating player controls.
- **Mobile Optimized**: Seamless touch navigation, audio unlock, and smooth 60fps rendering.

## Setup & Running Locally

1. Install dependencies:
```bash
npm install
```

2. Start the local development server:
```bash
npm run dev
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

3. Build for production:
```bash
npm run build
```
